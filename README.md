# Northline

Static studio portfolio built with React, Vite, TypeScript, Tailwind CSS, React Router, and Motion.

Sample content is fictional. Replace copy and case studies in `src/data` when you have the real material.

## Scripts

```bash
npm run dev
npm run build
npm run preview
```

## Structure

```
src/
  assets/        Logo and static marks
  animations/    Motion variants and easing
  data/          Site, project, and studio content
  pages/         One folder per route
  routes/        Paths and router
  widgets/       Shared layout, SEO, cards, motion
  lib/           Utilities
```
